# 校园驾校真实试点与反馈（证据登记）

> **当前状态：暂无经独立核实、允许公开的实际用户案例或真实使用反馈。**
>
> 这是未来收集证据的规范和空白表单，不是“已完成试点”或客户背书。不得虚构试点门店、参与者、下载量、转化率、节省工时或满意度。

## 真实试点门槛

1. 获得试点负责人同意使用系统，并明确是否允许公开匿名化案例。
2. 使用真实软件和已记录版本开展具体业务任务；不得把仅在测试数据上点击页面当成真实试点。
3. 记录基线与结果时，只写实测值并交代测量方法、样本量和误差。无法复核时写“尚未测量”。
4. 案例展示应去除客户姓名、联系方式、证件信息、订单详情及团队内部敏感信息，不能上传数据库原始备份。
5. 联系人反馈需有本人授权；匿名引用保留原话原意，不得编造推荐语或让模拟数据冒充客户。
6. 应记录失败、弃用、使用障碍和限制，避免选择性展示成功。

## 正式申请时的诚信边界

可以写：“项目已开源 MIT、包含网页版和微信小程序实现、CI 测试与部署文档，面向小型校园招生团队。”

**不能写**：“已被 XX 所学校使用”“帮助 XX 人提高 XX% 效率”“已有 XX 名用户”，除非有可审核的直接证据和授权。GitHub Star、Fork、下载量也应按提交当天实际数字填写。

任何记录真实用户信息前，先与合作单位确认数据保护、保存期限和公开边界。
